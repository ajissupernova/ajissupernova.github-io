DATABASE

Database Management

Sistem basis data untuk mencatat data produk, transaksi, dan laporan secara terstruktur, dibangun sebagai latihan merancang skema relasional.

PROJECT04TOOLSSQLMicrosoft AccessRelational Design

THE STORY

Proyek ini berfokus pada perancangan skema basis data yang bisa menangani data produk, riwayat transaksi, dan laporan ringkas tanpa duplikasi data yang tidak perlu. Saya memakai Microsoft Access untuk merancang tabel dan relasinya, lalu menyusun beberapa query SQL untuk menghasilkan laporan seperti total transaksi per periode. Latihan ini membantu saya memahami pentingnya normalisasi data sejak awal, sebelum aplikasi bertambah kompleks.

TAKEAWAY

Struktur data yang baik membuat pekerjaan berikutnya jauh lebih mudah.
