WEB DEVELOPMENT

Website Manajemen Klub

Platform sederhana untuk membantu pengurus klub sepak bola mencatat data pemain, pelatih, dan jadwal secara lebih rapi dibanding lewat spreadsheet.

PROJECT01TOOLSFlaskPythonSQLite

THE STORY

Proyek ini lahir dari masalah yang cukup umum di klub kecil: data pemain dan pelatih tersebar di banyak file, dan sulit ditelusuri saat dibutuhkan. Saya membangun backend dengan Flask untuk menyediakan API yang bisa diakses dari halaman web sederhana. Data pemain, pelatih, dan informasi klub disimpan di SQLite, sementara bagian tampilan memakai JavaScript untuk mengambil data dari API dan menampilkannya secara dinamis tanpa perlu memuat ulang halaman. Bagian paling menantang justru bukan di kode, melainkan merancang struktur data yang cukup fleksibel untuk berbagai kebutuhan klub tanpa membuat skemanya terlalu rumit.

TAKEAWAY

Belajar membangun sistem yang terasa masuk akal dari sisi pengguna, bukan hanya berhasil dijalankan.
